# Security Policy

Security fixes target the current `main` branch of this public portfolio snapshot.

Do not open a public issue for vulnerabilities involving license disclosure, customer/order data, authentication material, payment information, credentials, or a practical exploit path. Use the contact details on https://vovinhlac.com for private disclosure.

Include the affected component, reproduction steps, impact, and any suggested mitigation.

This public repository intentionally excludes production credentials, private license inventory, customer/order records, salts, database exports, backups, logs, payment secrets, and site-specific deployment configuration. If any secret is committed, rotate or revoke it before removing it from Git history.
